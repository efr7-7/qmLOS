THE WORKFORCE

Every person gets an agent

Not a chatbox that forgets you — a worker. Each employee’s agent remembers them, holds their keys in a keychain, runs their crons, and works on a durable computer where installed tools stay installed. Channels and projects get shared scopes, so the agent in #launch-week knows what #launch-week knows — and nothing it shouldn’t.

  • Isolated memory, files, keychain, and sandbox per scope
  • In Slack and on the web — same agent, same history
  • Capture a workflow once as a skill, promote it org-wide

UNIFIED TOKEN BUDGET

Budgets that refuse, not report

Allocations attach to the org, to nested teams, or to a single person. A soft cap warns. A hard cap refuses the turn — in the execution path, before the spend exists. Not a dashboard alert. Not an email three weeks after the invoice.

  • Team allocations aggregate their sub-teams automatically
  • Per-employee-per-month spend, at a glance
  • Managed live over one admin API call

ONE LEDGER

See every token, every engine

Every model call lands in a durable ledger with true input, output, and cache token counts — by model, phase, person, scope, session, and run. Not estimates. Not samples. Effective $/MTok and cache-hit share tell you what a model actually costs your org, and a cost-per-outcome leaderboard is where it’s headed.
